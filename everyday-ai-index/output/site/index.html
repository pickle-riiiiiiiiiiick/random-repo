Why

High scores, low usefulness

Some models rank near the top of every leaderboard and still feel weaker in daily use. Nobody needs to be cheating for that to happen.

  • Benchmarks test the model. I use a product.A leaderboard number is the model plus a test rig built by experts. I get the model plus whatever app it ships in. On Terminal-Bench 2.0 the same model moves more than 20 points depending only on the harness.
  • Short, clean tests hide the gap.Epoch AI puts open-weight models about four months behind. The gap is small on chat and wider on long, multi-step work, which is what a real day looks like.
  • Famous tests leak into training.Once a benchmark is well known, its questions turn up in training data and scores rise faster than ability. The 2026 AI Index found 2–42% invalid questions on major benchmarks.
  • Many headline numbers are self-reported.Launch-day scores come from the model maker's own runs. Independent re-runs often land lower.
  • Cheap is not the same as valued.On OpenRouter, Chinese models carry about 44% of the traffic, but closed frontier models take most of the money. People pay for what works on the jobs that matter.

It cuts both ways: a research harness built to win Terminal-Bench beats the everyday app running the same Claude model. Winning a test and being pleasant and safe to use are different things, so the index scores them separately.

How

Four layers, one score

I rate a setup: a model plus the app I reach it through. The same model in two apps counts as two setups. Each layer is scored against the best setup in the edition, so the scale never tops out.

  • App usability35%A 0–4 checklist of things I can see in the app, from file handling to asking before it deletes something.
  • My blind tests30%Twelve errands from my own month, run in every app and graded blind with the names hidden.
  • Model benchmarks25%Independent tests of finished work: GDPval, hallucination rate, tool use, METR time horizon, blind human preference. Exam-style tests like MMLU are left out.
  • Cost and limits10%What I'd pay per month, and how often I hit a limit.

The app

Nine things I check

Each scored 0 to 4 against things I can observe, so two people scoring the same app land within a point.

  • Gets it done end-to-end18%From request to a usable file, draft or result, without copy-pasting between apps.
  • Built-in tools14%Web search with citations, reading PDFs and spreadsheets, running code, making files.
  • Connects to your stuff12%Email, calendar, drive, notes, and an open connector standard for the rest.
  • Remembers context12%Projects, memory and long conversations that don't fall apart.
  • Recovers from mistakes12%Notices its own errors, checks its work, doesn't loop when corrected.
  • Safe control10%Asks before anything irreversible; undo and a clear record of what it did.
  • Speed and reliability10%Fast, rarely down, rarely capped, never cuts off a long answer.
  • Works everywhere you are6%Web, desktop, phone and voice, with history that syncs.
  • Low learning curve6%Good results from a plain request, without prompt tricks.

The tests

Nobody can train on my tasks

Twelve errands from my own month, from replying to a formal letter to reading a 60-page contract. Each one runs in every app. A script hides the names and shuffles the answers before I grade them.

The number I care about most is minutes of my time per finished task, prompting, checking and fixing included. It never maxes out: a better AI just pushes it towards zero. When an AI fails me on something real, that task joins the list; once every app passes a task twice, it retires.

Built to last

It outlasts the models

  • Skills stay fixed. The tests that measure them get swapped."Doesn't make things up" will matter in 2030, long after today's hallucination benchmark is retired.
  • A test retires once the leader passes 90%,or when the top three sit within noise, when it leaks into training data, or when only vendors still report it.
  • Scores are relative.The best setup in each edition sets 100, so the index never maxes out as everything improves.
  • Two numbers mean the same thing forever.My minutes per finished task, and the longest task an AI can finish on its own.
